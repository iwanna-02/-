# 光影本体汉化
Minecraft 光影着色器简体中文汉化项目

## 📖 项目介绍
本项目是对**光影本体包内原生文本**进行简体中文汉化，直接修改光影包内的语言/字符串文件，无需额外附属资源包加载。
汉化内容：光影设置面板、选项名称、提示描述、参数说明等。

> ⚠️ 重要声明
> 1. 本项目**仅翻译文本内容**，不修改光影渲染核心代码、算法，光影效果与原版保持一致。
> 2. 光影本体的版权、著作权归原光影作者所有。本汉化文件仅为玩家交流学习使用。
> 3. **禁止商用、二次打包售卖**；转载、分发本汉化内容请标注本仓库来源。
> 4. 使用前请备份原光影文件，防止文件损坏丢失。

## 📦 支持光影
> 在这里填写你汉化的光影名称+版本，示例：
> - BSL Shaders v8.2
> - Complementary Reimagined

## 📥 安装方法
1. 在 Releases 或者仓库下载对应版本汉化文件
2. 打开光影本体压缩包，找到对应的语言文件目录
3. 将仓库内汉化文件覆盖到光影包内（**务必先备份原文件！**）
4. 将光影包放入 Minecraft `shaderpacks` 文件夹
5. 进入游戏，加载光影，即可看到中文界面

> 💡 注意：
> 该汉化是直接修改光影本体文件，更新光影原版版本后，需要重新替换汉化文件。
